# FinTrack — Учёт личных финансов

Локальное и полностью автономное приложение для учёта доходов, расходов, переводов между счетами, бюджетов и аналитики.

## Возможности
- **Дашборд**: общий баланс, доходы, расходы, дельта и норма сбережений за период.
- **Аналитика (SVG)**: кольцевая диаграмма по категориям и столбчатый график динамики по месяцам.
- **Операции**: доходы, расходы, переводы между счетами, поиск, фильтры и сортировка.
- **Счета, категории и бюджеты**: произвольные кошельки, категории с иконками и цветами, месячные лимиты.
- **Экспорт и бэкап**: выгрузка в CSV (для Excel), полный экспорт/импорт в JSON, тёмная и светлая темы, выбор валюты.

## Структура проекта
- `desktop/` — веб-приложение на стандартной библиотеке Python (`http.server` + `sqlite3`), без внешних зависимостей.
- `pwa/` — автономная мобильная PWA-версия (`localStorage` + `manifest.json` + Service Worker).
- `android/` — Android-проект (Kotlin + WebView).

## Быстрый старт

### 1. ПК-версия (`desktop/`)
Требуется только Python 3:
```bash
cd desktop
python app.py
```
Или в Windows запустите `desktop/start.bat`.
Для сборки в `.exe`:
```bash
pyinstaller --noconfirm --onefile --name FinTrack --add-data "static;static" app.py
```

Запуск автотестов:
```bash
python -m unittest discover -s desktop/tests -v
```

### 2. Мобильная PWA-версия (`pwa/`)
Откройте файлы из `pwa/` по HTTPS (например, через GitHub Pages) в Chrome на телефоне и нажмите **«Установить приложение»**.

### 3. Android-проект (`android/`)
Откройте папку `android/` в Android Studio и нажмите **Build → Build APK(s)**.
